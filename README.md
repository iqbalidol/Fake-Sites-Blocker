## 🚀 Cara Pemasangan

### 1. AdGuard (Windows / Android / iOS / Browser Extension)
1. Buka **AdGuard** > **Settings** > **Filters** (atau **Custom Filters**).
2. Pilih **Add custom filter** / **Tambah filter kustom**.
3. Tempelkan (*paste*) URL Raw dari daftar di atas.
4. Klik **Next** lalu **Save**.

### 2. uBlock Origin
1. Buka **uBlock Origin Dashboard** (Settings).
2. Masuk ke tab **Filter lists**.
3. Gulir ke bagian paling bawah, centang opsi **Import...** di bawah kategori **Custom**.
4. Tempelkan URL Raw ke kolom teks yang muncul.
5. Klik **Apply changes** di sudut kiri atas.
